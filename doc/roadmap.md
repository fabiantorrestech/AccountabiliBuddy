# AccountabiliBuddy roadmap (full text)

Moved verbatim from the project CLAUDE.md on 2026-10-26.

MVP milestones M0–M7 (setup → core → watcher → app shell → enforcement → browser → OCR → logging) are done, plus the quick-session popup and two anti-escape passes (Setup lock, session resume, unseen browser windows, unlocks, off days; delayed looser changes, unknown escalation, ask about unlisted sites, scheduled end-early wait), the Exceptions tab (time off, one-off blocks, in-app events, iCal links, Google Calendar), the setup assistant (imports from Cold Turkey, AppBlock, BlockSite, LeechBlock, pasted lists), backups and the Velopack installer, the day bar (planned vs actual focus, events, live now line) and the on-screen window (click-through, Ctrl+Alt drag): per-profile session timer with a global default (styles, marks) and the all-day timeline (days with focus blocks; swaps with the timer or stacks); hover fades it, Ctrl+Alt Hide button; closed, minimized or off every screen from outside, it comes back at the next tick, and the tray has "Show on-screen window again" (works during focus); white glow + chime when focus or a break is up; sleep mode (day bar runs wake to bedtime, night and lost sleep shaded, evening "sleep if you go now · up <wake>" countdown from when bed would give the sleep goal, coloured against the goal; Ctrl+Alt on the on-screen window changes tonight's wake time by 15 minutes for that night only). Android companion (`android/`, plan in `doc/plans/android-companion.md`): imports the PC's backup (profiles v4, sleep, day bar, events; readable or password), Today/Profiles/Settings, Health Connect sleep, pinned colorized timeline notification (foreground service, BridgeCal pattern), home-screen widget, bedtime reminder, phone use vs. planned focus (Usage access), Curbox status via its API; PC remote designed (ADR 14, Proposed). Cold Turkey status (Session tab card from a copy of its settings; per-profile expected blocks, named at focus start; Cold Turkey is never changed: editing its settings file was tested and it rewrites it from its own copy). Quick Start (no set end; the on-screen bar fills each hour, glows every 30 min with the time in): the start panel (quick session and Session tab) has a big teal "Quick Start with Default" on top (the default profile: "QS - Default", made on every install at launch with starting rules (Windows basics, Office and chat, developer tools allowed; common distractions blocked), or another chosen in Settings; the old auto-made "Quick Start" is renamed once) and "Quick Start · <profile>" for the profile picked there. Linked devices (`doc/plans/linked-devices.md`, ADR 14-16 Accepted): L5 done; L1 built (Core `Link/`: framed JSON over pinned TLS, pairing by QR code from Setup → Linked devices, start and end early from the phone with the PC's own wait and reason; Android `link/` + PC card); L2 built (the PC pushes profiles, sleep, day bar and visible-calendar events as a hashed `settings` message; no more backup imports); the phone finds the PC again by one UDP "where" broadcast when its address changed (`LinkDiscoveryResponder`, same port). Verified on the user's PC and Pixel 7. The PC listens only while Windows marks its Wi-Fi/Ethernet network Private (`INetworkTrust`, `WindowsNetworkTrust`; paused with a Setup note on Public). Profiles tabs on both apps group by device once linked (this device first; profile count, running or "blocks on" profile, last seen/synced; the phone uses the PC's profiles). Noise player (sidebar bottom left and the on-screen window's Ctrl+Alt details: ⏮ ⏯ ⏭, repeat on by default, own volume, a pencil to rename how a file is shown (the file keeps its name); the sidebar keeps its width and long names are cut with "…"; a folder of sounds chosen in Settings, Music\Noise by default; Windows' MediaPlayer via `INoisePlayer`/`WindowsNoisePlayer`, created on first Play; media keys off by default; global shortcuts incl. arrows/Page Up/Down). History breaks Reddit, YouTube and GitHub down by subreddit, channel and repo under their site, in Most used and Top distractions (ADR 17, DB schema 4; past Reddit/GitHub entries filled in once from their encrypted addresses). Next: the body-double redesign (`doc/plans/2026-10-20-body-double-design.md`, approved; AB notices drift and hands sites to the blockers, which enforce). B1 built (`doc/plans/2026-10-20-day-plan-b1-plan.md`): schema v5 day plan, the Day plan tab (drag bar + list, categories, workdays), one-off days in Exceptions, sleep from the plan, no scheduled sessions, phone reads v5. B2 built (`doc/plans/2026-10-20-timeline-b2-plan.md`): the day bar and the on-screen timeline are rows (Calendar in calendar colours, Plan in category colours, Focus with red drift marks from History, work time with no session in slate and ticked tasks as white marks (legend: focused, Distracted, Not in a session, tasks done; not a day plan category), Blockers = Cold Turkey's blocks striped amber; order, rows, calendars and Cold Turkey set in Settings → Day bar); the phone's Today header, notification and widget draw the plan's parts in their colours. The phone has an app header (logo + name). Settings is a side list of five groups (Focus sessions, Your day, On screen & sound, Overlay (on-screen timer and timeline; the timeline has its own opacity at rest and while Ctrl+Alt is held when no session runs), App & data) with one group's sections as cards; app-wide search (top-right box, Ctrl+F, `doc/plans/2026-10-20-settings-and-search-plan.md`): typing highlights matches on the page showing (`SearchHighlightLayer`), "Search All Results…" lists the user's things (profiles and rules, day plan, one-off days, events, History apps/sites from readable columns) and the app's words (`UiSearchSource`), and opening one goes to its tab, profile, date or Settings group; nothing is stored or sent. An About tab (after Settings) shows the icon, version, the camp quote and Updates (moved out of Settings). The phone edits the whole day plan (ADR 19, `doc/plans/2026-10-20-phone-day-plan-editing-plan.md`: "Edit plan" on Today; drag bar, Workdays/Off-Days/one-off days/categories; an edit waits on the phone until the PC takes it). Pixel Watch companion (ADR 21, `doc/plans/2026-10-21-watch-companion-plan.md`): the PC sends paired devices today's focus ("focusDay": plan parts, counted sessions cut at midnight, drift, focused/planned minutes, the 7 days ending today; `FocusDayBuilder`); the phone keeps it and sends the linked watch a snapshot (`android/shared` `SnapshotBuilder`, `WatchBridge`: at once on a session start or end, else at most every 10 s; the watch app's "/hello" makes the phone connect to the PC for a moment); the watch shows Today (plan and focus on a 24-hour ring), the session, the last 7 days and where the data comes from, plus a Tile and a complication, and asks the PC itself over Wi-Fi when the phone hasn't answered for 2 minutes. Not yet tried on the watch. Next: flexible lunch, B3 phone screens (four rows on the phone), the buddy, session checklist/reflection, progress. Cold Turkey's command line `-add "<block>" -web <site>` reaches a running Cold Turkey at once (tested on a throwaway block). L3-L4 after that. Backlog: progress heatmap; Shorts/Reels and part-of-site blocking on the desktop (from Curbox). Device sync (ADR 22, `doc/plans/2026-10-21-device-sync-plan.md`): built. The phone's sync folder (Devices → Sync folder (backup), off by default) reads and writes a folder another app such as Autosync keeps in step with Drive, every 15 min, 1 or 5 min while the timeline notification is pinned (`DriveFolderSource`). Sealed per-device files (`Core/Sync`, `android/shared/.../sync`), merged by `SyncMerge` (no double sessions; history off deletes that device's sessions); link a device by its link code or QR (Devices tab on both); the PC writes and reads a sync folder and shows today's QR codes (on-screen window QR button, end-of-work reminder), imports and shares files, and keeps a running log; the phone joins, scans, carries the other devices' files over the ADR 14 link and shares; the Today page, notification, widget and watch show the combined day; the PC's Devices tab lists every device (state pill, last seen) with the phone's linked watch indented under it; the phone's Devices tab lists itself first with its linked watch indented under it; rows on both start with a small PC, phone or watch outline (`DeviceKind.iconPath`, the same SVG path on both). The first run asks three questions (What kind of computer is this? (with "Guard work hours here" on Personal), Link to your other devices?, How much focus a day?; `AssistantFlow`); the full setup (More → Setup → "Full setup (imports, browsers)") starts with "Link to your other devices?" and "What kind of computer is this?" (Local only, Work computer, Personal computer: privacy, escalation ceiling, sharing methods, update checks; Settings → App & data applies one again). The watch Tile draws today's ring (plan, focus, drift ticks, a moving now tick). The phone's notification, Today header and widget say what fits the moment (`DayHeader`: a session's time left ticking live, the plan's part now, what starts within the hour, done for today/bedtime/past bedtime, day off; summary: focus of plan across devices, drifts, phone screen time, wake and sleep ahead) and draw the PC's rows (Calendar in calendar colours, Plan, Focus with drift; a thin measured-sleep strip; the PC's row order; 3 dp now line). The watch app shows the running timer first while a session runs (with the current task) and buzzes when a focus or break ends (Alerts page: vibration off/light/medium/strong, sound, 1-minute warning; exact alarms set from the snapshot, so it buzzes without the phone). Guided sessions (ADR 24, 25): tasks with subtasks before Start (quick-session popup, Session tab) and while running (Session tab Tasks card; the on-screen window's task line, and its Ctrl+Alt checklist to tick, done collapsed; click a task or subtask's name, there or in the app, to show it on the bar (▸; ticking it moves to its task's next open subtask; the bar reads "1/3 ▸ task" on one line and the subtask under it, 2 lines then "…", all of it while Ctrl+Alt is held, when each line also gets a box to tick it); rename (✎, Enter or click away keeps it, Esc cancels) and move (↑ ↓) tasks and subtasks in the app's lists); tick times recorded; "All tasks done" notice and end at once; the checklist reaches the phone (link state and sync files) as a read-only Today card. The phone's wake-up alarm is its wake time and the PCs' (ADR 23; the app whose alarms go off in the sleep window on 2+ mornings is learned, calendar apps never count, pin one in Devices; another app's alarm shown next doesn't hide it (`WakeAlarm`); phone Devices → "Next alarm as wake time", PC Settings → Sleep). Ctrl+Alt + double-click on the on-screen window, or its Open button, opens the app. The phone has the noise player too (`android/app` `noise/`: a folder of sounds picked with Android's folder picker, a bar above the tabs with ⏮ ⏯ ⏭ and its own volume, repeat on by default, a media-playback foreground service with a quiet notification; Settings → Noise player: "Use Android's media controls" (off by default: no media session or audio focus, so other audio such as YouTube plays over it) and "Play/pause on the widget" (on by default); it opens no connection). The phone's tabs fold to short summaries (`Section(title, summary)`), explanations behind an ⓘ (`Hint`). Redesign (`doc/plans/2026-10-22-redesign-design.md`): phase 1 built (`doc/plans/2026-10-22-redesign-phase1-plan.md`). Tabs in tiers (`MainTab`: Today, Profiles, Day plan, Calendar (was Exceptions); History, Devices; More unfolds Setup, Integrations, Settings, About; the day bar only above Today and History). The Today page (`TodayView`, still `SessionViewModel`; `SessionView` is unused and kept until the user OKs deleting it): tasks first ("What are you doing first?"), the big teal Quick Start with Default, "Start 25 min focus", and "More options" (profile, length, break, Quick Start · profile) folded; the quick-session popup shares the panel. Focus mode while a session runs (`FocusViewModel`/`FocusView`): the sidebar shows only Today and History plus "Show everything" (back for that session); the page shows the countdown (frozen while away), the phase line, End session, the focus so far, the current task and subtask in front with the checklist, and Step away / Interrupted (an "Away · 4:12" badge, "I'm back"); opening the window during a session lands on Today. Away stretches are hatched slate on the Focus row (`DayBarSpan.IsAway`). Step away and the quiet on-screen window (quiet by default: 60% and slate at rest, red marks kept; full colour while Ctrl+Alt is held, in a phase's last 2 minutes and when time is up; the timeline's now line moves every second; Settings → On-screen timer → At rest: Quiet / Full colour; an "Away · 4:12" badge and a Ctrl+Alt Step away button). Next: phase 2 (prompt calming, learn mode, section K's local part: the personal PC's Work-hours profile, the gate, the come-back key). Profiles: tick rules (or Select all) and Copy or Move them to another profile or "New profile…" (asks: from this profile's settings or brand new); a rule the target has (same match, how, pattern any case, verdict; `RuleTransfer`) isn't copied twice; it's an ordinary edit until Save. 12-hour times (2026-10-23, done): the PC app's culture tells time "h:mm tt" whatever the Windows region (`TwelveHourClock`), its time pickers use the 12-hour clock, and the phone and watch ignore Android's 24-hour setting; see Conventions. Feature-list run (2026-10-26, `doc/plans/2026-10-26-*`, the user's Obsidian list): local timers and alarms on every device (PC document "timers": a Today card, a bar per timer on the on-screen window, glow + chime (the bell if "Focus ends" is Off), ring windows that never take focus; phone prefs "timers": a notification per timer with a live countdown, exact alarms that never count as the wake-up alarm (ADR 23), a full-screen ring; watch: its own Timers page and a second "Timers" complication beside the Focus one; nothing leaves a device; synced timers wait for a relay); a phone test session (prefs "testSession": 1-60 minutes, runs the phone's own session reactions, never counted, synced or sent to the watch); the Notebook edits and deletes come-backs and notes; other blockers detected, status only (PC: Freedom, PluckEye; phone: AppBlock, StayFocused, Freedom); a self-hosting guide (`doc/guides/self-hosted-sync.md`, shipped in `guides\`, short steps in both apps' Devices: Syncthing or Nextcloud through the existing folder method). Waiting on the user: deleting the Wi-Fi link (ADR 42 moved its jobs to sync files), the sealed relay program, the day plan rework, the Claude Design batch. Post-MVP: V2 habit suggestions + distilled local classifier (synthetic frontier-generated data; real samples opt-in and redacted only); V3 Android companion + LAN/Bluetooth sync, Linux, tamper resistance.
