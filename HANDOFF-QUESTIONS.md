# HANDOFF-QUESTIONS (Tasks redesign, PC + shared model run)

Ambiguities found; each has a choice already made (closest to the prototype / safest for the hard rules). Update as the run goes.

## Needs the owner

Each has a working default already built; only these need your call (details in the rows below).

1. **Q225** "New reminders start at": default At start time (brief) or None (spec 05, P11)? And confirm the follow-up: a task's first due time gets this reminder (nothing applies the setting yet).
2. **Q226** Default time limit for new tasks: 25 min (spec 02) or None? Since this run new tasks typed in an add box start with 25 min.
3. **Q223** Session view: Quiet = stricter, Grouped waits the looser-change wait. Flip it?
4. **Q254** "During a focus session": Remind quietly treated as looser (waits, refused during a session). Keep?
5. **Q190** Quiet reminders during a session ring the bell once. Silent instead?
6. **Q242** A device linked later: joins "every device" lists, but stays off on a restricted list until ticked. Should new devices join restricted lists too?
7. **Q243** Other PCs can't be turned off in Rings on (each PC always rings for its own). The prototype lets them toggle. Keep locked?
8. **Q257/Q267** Start fresh resets the default view for every device when the account holds one (per-account rule); with nothing in the account it writes nothing. Intended?
9. **Q260** Not built: "Make it its own task" (step → task) and the Sync now toasts. Build them in a follow-up, or drop?
10. **Deletes** (each needs your yes): the stand-in reminder window `TaskReminderWindow` + `TaskReminderRingViewModel` (Q193); the old Undo bar `UndoBarView` + `UndoBarViewModel` (Q209); the unused filter view models `TaskFilterViewModel`, `TaskFilterPresetsViewModel`, `TaskFilterPresetRowViewModel` (Q102).
11. Smaller: Q198 (a toast's timer pauses under the pointer), Q20 (come-backs show "Parked <time>" rather than "Come back to").
